## 🚀 Overview

The **Library Management System** is a menu-driven console application developed using **C++** that helps manage books, borrowing operations, and library records efficiently.

This project supports:

✅ Adding Books

✅ Displaying Book Records

✅ Searching Books by Title or Author

✅ Issuing Books

✅ Returning Books

The system uses **Object-Oriented Programming (OOP)** concepts and **File Handling** to maintain persistent library records.

---

# ✨ Features

## 📖 Add Book

Add new books into the library database.

## 📋 Display Books

Display all available library records in formatted tabular form.

## 🔍 Search Book

Search books using title or author name.

## 📕 Issue Book

Issue books to users and update availability status.

## 📗 Return Book

Return issued books and restore availability.

## 💾 Persistent Storage

All records are stored using:

```text
library.txt
```

This ensures records remain saved even after closing the program.
